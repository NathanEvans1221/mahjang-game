# 麻將網頁版 UI 優化設計

- 日期：2026-09-15
- 狀態：待審閱
- 範圍：版面、視覺、動效；不碰遊戲流程、判定與計分邏輯

## 1. 目標

把「功能型素顏」介面升級為有桌感的四方桌：方位可辨、副露可見、計分可讀，
手機可順暢出牌。既有 62 項測試保持全綠。

## 2. 非目標

- 不改 `game.js` 回合流程、`player.js` 判定、`scoring.js` 計分、`ai.js` 決策
- 不引入前端框架與圖片素材（純 CSS）
- 不做音效（留待後續）

## 3. 版面佈局

- 四方桌：南（人類玩家）在下、北在上、東/西分居左右
- 中央區：剩餘牌數、回合指示、莊家燈號、連莊數
- 每家三區：手牌區、副露區（吃碰槓面子橫置）、棄牌河
- 頂部計分條：四家名稱、台數/分數
- 底部動作列：吃/碰/槓/胡（沿用現有按鈕與啟用邏輯）
- Mobile（≤640px）：南家手牌橫向捲動，牌面縮小（沿用現有斷點機制）

## 4. 視覺風格

- 桌面：墨綠氈質感（CSS 漸層＋雜訊用 repeating-linear-gradient 模擬）
- 牌面：米白漸層、頂部高光、底部厚邊陰影；牌背藏青菱格紋
- 花色配色：萬＝墨黑、條＝竹綠、筒＝正藍；字牌描金框
- 沿用 `css/style.css` 現有 CSS 變數並擴充（`--felt`、`--tile-face` 等）

## 5. 動效

全部使用 CSS transition/animation，並受 `body.no-anim` 開關控制：

- 出牌：從手牌滑入棄牌河（transform 位移）
- 摸牌：新摸入牌短暫高亮（outline 脈衝一次）
- 可行動按鈕：呼吸燈（box-shadow 脈動）
- 胡牌：中央彈出＋CSS 粒子簡版撒花
- 關閉動畫時：以上全部靜止（沿用現有 `no-anim` 規則並擴充）

## 6. DOM 與程式變更

- 重寫 `renderPlayers`：依方位產生桌位容器（`.table-seat.north/south/east/west`）
- 擴充 `updatePlayerArea`：渲染副露區（`.meld-area`）與棄牌河，兩段式出牌保留
- `index.html`：新增中央資訊區與計分條容器，沿用 `<template>` 機制新增牌桌模板
- 新增 CSS 區段：桌位、中央區、計分條、副露橫置、動效 keyframes、RWD 擴充
- 不新增 npm 依賴；結構測試沿用現有 stub 模式驗證節點生成

## 7. 測試計畫

- 既有 62 項全綠（迴歸門檻）
- 新增：副露區渲染（吃/碰/槓各一）、中央區資訊（剩餘牌數、莊家）、計分條節點存在
- 手動驗收：Desktop 四方桌、Mobile 出牌流程、`npm run build` 成功

## 8. 驗收標準

1. Desktop：四方桌完整顯示，方位、副露、棄牌河、計分條齊全
2. Mobile 640px：南家手牌可橫滑並完成選取→出牌
3. 動畫關閉時所有動效靜止
4. `npm test` 全綠、`npm run build` 成功、`git diff --check` 通過
